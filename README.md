# 類題何切る量産ドリル

2026-09-03: 修正版エンジン 0.9.15 を反映しました。残り枚数から経過巡目を重ねて差し引いていた計算を修正しています。赤5と普通の5は打牌・期待値・解答判定で区別し、旧エンジンの保存済み計算結果は再計算対象になります。

Googleログインによる端末間同期を利用する場合は、[FIREBASE_SETUP.md](FIREBASE_SETUP.md)に従ってFirebase AuthenticationとCloud Firestoreを設定してください。未設定時は従来どおりブラウザ内だけで利用できます。

何切る問題を出題・復習しながら、元問題から類題を自動生成するブラウザアプリです。

## できること

- ジャンル別に問題を出題
- 忘却曲線に基づいた復習出題
- 元問題を反転・置換・スライドして類題を自動生成
- 何切るシミュレーターで元解答と類題を検証
- 成績をジャンル別・日付別に確認
- 問題、回答状況、成績をブラウザの `localStorage` に保存
- 保存内容を Base64 で出力・復元

## 保存について

問題や学習履歴は、このブラウザの `localStorage` にだけ保存されます。サーバー側の保存やパスワードは使いません。

## 使い方

1. `launch_admin.bat` を実行して起動します。
2. 「問題作成」で手牌、副露、ドラ表示牌、指定解答、巡目などを入力して検証します。
3. 条件を満たしたら元問題を登録するか、類題を生成・登録します。
4. 「出題」でジャンル別出題や復習出題を行います。
5. 「データ出力」から Base64 を保存してバックアップできます。

## 問題作成のルール

- 同じ手牌と副露の組み合わせは重複登録できません。
- 指定解答は複数個登録できます。
- 類題生成では、元問題を変換しても指定解答の乖離率が許容範囲内に収まる候補だけを採用します。
- 高速類題生成では、重複を除いた候補を加工度別ビームに分け、高速推定で順序付けした候補を厳密DPで判定します。合格変換の近傍を探索しつつ、採用加工度が一種類に偏らないよう制御します。
- 類題生成中は「ここまでを登録して停止」で計算中の候補を中断し、元問題と完成済みの類題だけを保存できます。


## WebAssembly エンジンの更新

ブラウザ版は `engine-lock.json` で BigCoach と同じ
`Haura900/mahjong-cpp` リリースに固定しています。エンジン本体とWASMの
ビルドはエンジン側で管理し、このリポジトリでは検証済み成果物だけを
`docs/wasm/` へ取り込みます。

```powershell
npm run engine:update
```

## 補足

ログインしていない場合は問題データをブラウザ内に保存します。Googleログイン時は、問題・問題別学習履歴・設定をFirebaseのユーザー専用領域へ同期します。バックアップはgzip圧縮とBase64化を行いますが、暗号化はしていません。
