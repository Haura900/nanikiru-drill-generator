概要・使い方

このアプリでできること

麻雀の「何切る問題」を出題・復習しながら、元問題を元に類題を自動生成できるブラウザアプリです。

主な機能

  • 出題：ジャンル別に何切る問題を出題します
  • 復習：忘却曲線に基づいた間隔で復習問題を出題します
  • 類題自動生成：元問題を部分反転・ブロックずらしして作った候補を、何切るシミュレーターで確認してから登録します
  • 成績管理：ジャンル別、日付別の成績を見やすく確認できます
  • データ保存：ログインなしではこのブラウザに保存し、Googleログイン時は端末間で同期できます

データについて

ログインしていない場合、問題と学習記録はこのブラウザだけに保存されます。

Googleでログインすると、問題・学習記録・復習設定がFirebase上のユーザー専用領域に保存され、同じGoogleアカウントを使用する端末間で同期されます。

同じ問題を複数端末で変更した場合は、端末に記録された変更時刻が新しい状態を採用します。端末時計が大きくずれていると判定に影響するため、各端末の日時を自動設定にしてください。

セーブデータは転送しやすい形式に圧縮していますが、暗号化はしていません。

  • 同じブラウザでも、保存先が違うと見えません
  • ブラウザの保存領域を消すと失われます
  • 定期的に「データ出力」からBase64を保存してください

復習スケジュール

出題時の正誤に基づいて、次回の復習日時を自動計算します。間隔はデータ画面から調整できます。

  • 初見正解：設定した日数後
  • 不正解：設定した日数後
  • 不正解直後の正解：設定した日数後
  • それ以外の正解：(前回からの日数 × 設定した係数 + 設定した日数) 後
